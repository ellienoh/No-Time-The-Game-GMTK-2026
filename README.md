# No Time!!! - GMTK Game Jam 2026
A short 2D platformer, where you utilize time reversal and time slowing mechanics to avoid obstacles and reach the goal.
This game is a small solo project of mine that I wanted to try :)

## Where to play it?
On itch.io: https://nohwon.itch.io/theres-no-time

## Development
This game was created on Unity with C#.
All assets used are either preset Unity assets, drawn by hand, or copyright-free.
